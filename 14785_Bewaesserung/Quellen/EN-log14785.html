14785 – Irrigation 5 circuits (cascadable) (v1.0)

Block ID 14785Version 1.0HSL 3.0

Garden irrigation with 5 circuits per block. Any number of blocks can be chained (master → follower 1 → follower 2 …), e.g. 2 blocks for 10 circuits.

Function

  • Run time 0 = circuit skipped. The weather factor (I9) scales all run times.
  • Run 1 = all circuits with a run time. Run 2 (12 h later) = only circuits with cycle 2.
  • End time instead of start time: I8 sets when run 1 shall be finished. The master calculates the total run time of the whole chain (O8/O9) and starts by itself at the recommended start time (O10–O13). A time switch is only needed for the days (I5 automatic).
  • Order: circuits run in number order. Parallel allowed = 0: runs alone (sprinklers); = 1: runs with other parallel circuits up to I16 (drip lines). Parallel only within one block.
  • Manual start (circuit input = 1): without a running program a manual run (O5 = 3) starts incl. PSU and pump; during a program the circuit is appended or started afterwards. 0 stops it.
  • Rain lock per circuit, active after I11 s of continuous rain, held for I12 min. Running circuits with rain lock are stopped, waiting ones skipped.
  • Frost lock for all circuits (1 K hysteresis). Watchdog I19. After a HS restart all valves are closed.

Supply (master only)

  • 24 V PSU (O1): mode 0 = during runs, 1 = permanent, 2 = run + refill window I23.
  • Pump (O2): on-delay after valve (I24), pressure relief before last valve (I25).
  • Case A – autonomous refill (float switches a 24 V valve directly): leave I26/I27 free, use PSU mode 2 or 1. No dry-run protection by the block.
  • Case B – float on KNX: I26 (1 = empty) starts O3, I27 (1 = full) stops it, otherwise I29. Empty longer than I30 during a run → run paused until water is back.

Cascade

  • First block I1 = 0 (master), further blocks I1 = 1 (follower), I2 = first circuit number (6, 11 …).
  • One text iKO per direction: O19 → I3 of the next block, O20 → I4 of the previous block.
  • Recommendation: overlap I18 = 2–5 s.

Creating iKOs

  • Fastest via Experte CSV import: Communication objects → Extras → Data synchronisation → synchronise/import CSV file. Create setting iKOs as retentive.

To be verified on the HS: time object (DPT 10) at I8/O10/O12 – otherwise use a 14 byte text "06:00" at I8 and O11/O13.
