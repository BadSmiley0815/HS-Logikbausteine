1.Description

Scene control with its own web page (desktop and mobile view), replacing per-function grids of matrix blocks. Functions (light, RGBW, blinds, gates, roof windows, heating) are taken from the HomeServer CO structure on the page; the page builds itself from them. On a scene call the block sends all enabled values via the CO gateway (WebSocket) – no wiring per function.

• Value of the active scene changed → stored and sent immediately; inactive scene → stored only.
• Conditions per function (only for values > 0, off/close always passes): dusk, rain (do not open, restore afterwards – remanent), summer/winter rows (based on DIN: daily mean (T7 + T14 + 2·T22) / 4 ≥ 16 °C = summer; sampled at 7, 14 and 22 h, remanent; outputs O13–O17).
• Blinds/roof windows: per scene 1-bit move (long) or position 0–100 %. RGBW: colour wheel, white, brightness.
Attention
I2 must be set in the Expert (8093). If it is 0 the HomeServer does not forward requests (503 Service Unavailable).
Note
CO gateway like the HTML5 visu: HS address, user and password are entered on the web page under Connection (not in the Expert). The page hands the access to the block so scenes are also sent without an open page.

Scene calls are most reliable via I5 or I6–I13: the HomeServer calls the block on every telegram. The CO gateway reports values on change only – the same scene value twice in a row via a scene CO on the gateway may arrive only once.

5.Web page and operation

Open: https://<HS>/szenen/, enter the key from I3.
CO gateway (like the HTML5 visu): plug icon → HomeServer, user, password, encrypted; “also store in block” (default) hands the access to the block for scene calls without an open page.
Setup: gear icon → group (name, number of scenes, scene CO DPT 17.001 or block input), sensors for all groups (dusk, rain, outdoor temperature CO, summer limit with live value), catch-up. Arrow down → import functions from /hscl?sys/cobjects.xml (enable “load XML structure of the COs to the device” in the Expert). Pencil → sort, edit functions, scene names.
View: icon top right: automatic / mobile / desktop.
Debug: click the connection dot to see all messages between block and CO gateway.
Backup: gear icon → download / restore backup (JSON).
