1.Description

Fetches still images and live images from up to 6 network cameras and serves them through the HomeServer forwarding – same address and certificate as the HS. The browser does not log in to the camera; credentials are stored in the module only.

• Cameras: Axis, any camera with a still image URL, or ONVIF (the module discovers the URLs itself).
• Camera login: digest or basic, for ONVIF also WS-Security. http or https; self-signed certificates are accepted.
• Live image: the camera's MJPEG stream is passed through. If the camera offers none, the module builds the stream from still images.
• Test page at https://<HS>/kamera/.
Attention
I2 must be set in the Experte (8095). With 0 the HomeServer does not forward (503 Service Unavailable).

5.Camera address

EntryTypeBehaviour
<camera>
https://<camera>		AxisStill image /axis-cgi/jpg/image.cgi, live image /axis-cgi/mjpg/video.cgi. Needs a regular Axis account.
https://<camera>/path/image.cgi?…Still image URLExactly this URL is fetched as still image. Live image built from still images.
onvif://<camera>ONVIFProfiles and snapshot URL are discovered via ONVIF (https first, then http). Resolution: onvif://<camera>?resolution=1280x720 (default 1280x720). Live image built from still images.
