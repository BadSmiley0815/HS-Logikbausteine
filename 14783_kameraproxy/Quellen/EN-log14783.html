14783 Camera proxy – version 0.1 (test release)

ID 14783 · version 0.1 · HSL3 · BadSmiley0815

Fetches still images and MJPEG streams from network cameras (e.g. Axis) using digest or basic authentication and serves them through the HomeServer forwarding (same address and certificate as the HS): https://<HS>/kamera/<name>.jpg?k=<key>, …/<name>.mjpg?k=<key>, test page https://<HS>/kamera/, JSON check …/test?k=<key>.

Inputs: I1 base path (kamera), I2 port (8095, never 0), I3 key, I4 restart, then per camera (3×) name, address, user, password. Outputs: O1 status, O2 requests, O3 active streams, O4 last check. Credentials are never output or logged.
